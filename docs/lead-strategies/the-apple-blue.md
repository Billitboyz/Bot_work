# Sales Strategy — The Apple Blue

## Goal
Increase event attendance and group/private booking enquiries.

## Offer Positioning
- "Go-to venue for social nights, live events, and private group bookings."
- Sell experience + convenience.

## Funnel
1. **Social/Event discovery** → event-led landing page
2. **Primary CTA**: View events
3. **Secondary CTA**: Reserve a space
4. **Lead capture**: private hire form + callback option

## Conversion Assets
- Weekly events block with date + seat urgency
- Promo banners (quiz nights, 2-for-1, sports screenings)
- Trust stack: ratings, capacity, testimonials, logos

## Sales Actions
- Segment promotions by weekday vs weekend intent
- Add dynamic "next event" hero module
- Trigger follow-up workflow for private-hire enquiries

## KPI Targets (30 days)
- +20% event RSVPs
- +25% private-hire enquiries
- +15% group bookings
