# Sales Strategy — Panda's Coffee House

## Goal
Drive footfall and build an owned audience (email/SMS) for repeat revenue.

## Offer Positioning
- "Best coffee in Balham" + community hub for remote workers/weekend brunch.
- Lead magnet: first pastry + coffee combo discount.

## Funnel
1. **Local SEO + map searches** → location-first landing page
2. **Primary CTA**: Get directions
3. **Secondary CTA**: Join coffee club
4. **Retention**: weekly offer + monthly loyalty campaign

## Conversion Assets
- LocalBusiness + FAQ schema
- Review highlights + social proof
- Fast opt-in form (name + mobile/email only)

## Sales Actions
- Add neighborhood keyword clusters to page copy
- A/B test discount value (15% vs 20%)
- Add "before 9am" commuter bundle promo

## KPI Targets (30 days)
- +25% direction clicks
- +300 new subscribers
- +12% repeat purchases from loyalty offers
