# Sales Strategy — Hanoi Eats & Boba

## Goal
Increase table bookings and online orders while improving repeat visits.

## Offer Positioning
- "Fast comfort food + fresh boba in Balham"
- Emphasize delivery speed + dine-in vibe.

## Funnel
1. **Ad/Local search** → landing page (book/order split above the fold)
2. **Primary CTA**: Book table
3. **Secondary CTA**: Order now (pickup/delivery toggle)
4. **Retention**: Collect SMS/email at checkout for weekly specials

## Conversion Assets
- "Top picks tonight" carousel (Pho Special, Lemongrass Chicken, Brown Sugar Boba)
- Local trust bar: rating, avg delivery time, dietary options
- Time-based promo: weekday lunch combo / evening bundle

## Sales Actions
- Set up Google Business profile post cadence (2x/week)
- Add UTM links for Book vs Order CTAs
- Capture abandoned order emails for remarketing

## KPI Targets (30 days)
- +20% online orders
- +15% booking conversions
- 10% returning customers via offer redemptions
